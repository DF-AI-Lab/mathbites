## Versioning
- Version lives in `index.html` (`const VERSION=...,VDATE=...`) and in the README "Version" line.
- Small fixes and tweaks: bump the last number only (1.14.0 → 1.14.1 → 1.14.2).
- Bump the middle number only for a big new feature, and only when Darren says so.
